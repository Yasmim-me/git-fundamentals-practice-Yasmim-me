# Git workflow reflection

at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: a commit saves your changes locally on your own computer, 
while a push uploads those saved local commits to a remote platform like GitHub 
so others can access them, for example I like to use IntelliJ that already has 
built-in Git tools

## 2. Why work on a branch instead of directly on `main`?

Answer: when working on an independent branch it lets you test new code and 
fix errors without messing up the original/working version on the main branch

## 3. What does a pull request make possible?

Answer: a pull request makes it possible for all the team members of the group to
see the code, discuss changes, run tests, quality before  of it before merging 
updates into the main branch

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: The git status command helped me understand the state of my repository by 
showing me that I was on the main branch with a completely clean working tree
and no uncommitted changes
